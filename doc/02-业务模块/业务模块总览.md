# 业务模块总览

本文件按代码命名和接口入口归纳业务模块。业务含义有些来自类名和表名推断，具体规则以后续阅读 Service 和 Mapper SQL 为准。

## 用户与团队

后台入口：

- `UserInfoController`：`/xms/userinfo`
- `UserLevelConfigController`：`/xms/userLevelConfig`
- `UserLevelChangeLogController`：`/xms/userLevelChangeLog`
- `UserInfoSnapshotController`：`/xms/userInfoSnapshot`
- `UserInvestLayerConfigController`：`/xms/userInvestLayerConfig`

App 入口：

- `UserInfoController`：`/userinfo`
- `BizUserServiceImpl`

重点表：

- `t_user_info`
- `t_user_relation`
- `t_user_info_snapshot`
- `t_user_level_config`
- `t_user_level_change_log`
- `t_user_invest_layer_config`
- `t_user_income_summary`

常见场景：

- 登录、注册、邀请码/推荐关系
- 团队列表、直推成员、团队视图
- 用户等级、层级配置、等级变更记录
- 用户资产和收益概览
