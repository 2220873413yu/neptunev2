# 技术栈与启动配置

## 后端构建

父工程：`xms/pom.xml`

关键版本：

- Java：21
- Spring Boot：3.3.4
- 项目版本：3.8.5
- MyBatis Plus：3.5.7
- PageHelper：2.1.0
- Druid：1.2.23
- Redisson：3.36.0
- MySQL Connector/J：8.2.0
- Swagger/Springfox：3.0.0

模块顺序：

- `xms-common`
- `xms-framework`
- `xms-system`
- `xms-quartz`
- `xms-generator`
- `xms-dao`
- `neptune-app`
- `neptune-admin`

## 管理后台服务

启动类：

- `xms/neptune-admin/src/main/java/com/xms/web/XmsApplication.java`

配置文件：

- `xms/neptune-admin/src/main/resources/application.yml`
- `xms/neptune-admin/src/main/resources/application-dev.yml`
- `xms/neptune-admin/src/main/resources/application-test.yml`
- `xms/neptune-admin/src/main/resources/application-prod.yml`

开发环境端口：

- `server.port: 19866`

关键配置：

- `spring.profiles.active: dev`
- `xms.auto-scan-package: com.xms`
- `xms.auto-scan-mapper: com.xms.**.mapper`
- `mybatis-plus.mapper-locations: classpath*:mapper/**/*Mapper.xml`
- `mybatis-plus.type-aliases-package: com.xms.**.domain`
- `xms.stream.enable: true`
- `xms.stream.consumerGroup: xms-admin`
- Redis DB：`spring.data.redis.database: 76`
- Druid 主库：`neptunev2`
- Canal filter：`neptunev2.t_user_money`

注意：配置文件中包含开发环境数据库、Redis、OSS、Udun、合约、第三方平台等敏感配置。后续文档和需求说明只记录配置键和用途，不复制密钥。

## App/API 服务

启动类：

- `xms/neptune-app/src/main/java/com/xms/app/AppApplication.java`

配置文件：

- `xms/neptune-app/src/main/resources/application.yml`
- `xms/neptune-app/src/main/resources/application-dev.yml`
- `xms/neptune-app/src/main/resources/application-test.yml`
- `xms/neptune-app/src/main/resources/application-prod.yml`

开发环境端口：

- `server.port: 19865`

关键配置：

- Swagger 开启：`swagger.enabled: true`
- Redis Stream：`xms.stream.enable: true`，`consumerGroup: xms-app`
- WebSocket：`websocket.enable`、`websocket.server.*`
- App token：`token.header: Authorization`
- 数据库：`neptunev2`
- Redis DB：`76`
- 短信、Udun、合约、Dify/robot、Volcano、CoinGlass 等第三方配置存在

## 前端构建

前端项目：`xms-ui`

关键版本：

- Vue：2.6.12
- Element UI：2.15.12
- Vue CLI：4.4.6
- Axios：0.24.0
- ECharts：5.4.0

脚本：

- `npm run dev`：本地开发
- `npm run build:prod`：生产构建
- `npm run build:stage`：预发布构建
- `npm run lint`：lint

代理配置：

- `xms-ui/vue.config.js`
- 使用 `process.env.VUE_APP_BASE_API` 作为代理前缀
- 使用 `process.env.VUE_APP_TARGET` 作为目标后端

## 基础设施入口

安全与认证：

- 后台：`xms-framework` 与 `neptune-admin` 下 RuoYi 安全配置
- App：`xms/neptune-app/src/main/java/com/xms/app/security`
- Token：`AppTokenService`

Redis：

- 常量：`xms/xms-common/src/main/java/com/xms/common/constant/RedisConstant.java`
- Stream：`xms/xms-common/src/main/java/com/xms/common/config/redis/stream`
- Redisson 延迟队列：`xms/xms-common/src/main/java/com/xms/common/config/redis/delayqueue`

定时任务：

- Quartz 管理：`xms/xms-quartz`
- 业务任务 Bean：`xms/neptune-admin/src/main/java/com/xms/web/task/XmsTask.java`

数据库：

- Domain：`xms/xms-dao/src/main/java/com/xms/dao/domain`
- Mapper XML：`xms/xms-dao/src/main/resources/mapper`
- DDL：`xms/a-doc/script-DDL/V1.1/DDL.sql`
