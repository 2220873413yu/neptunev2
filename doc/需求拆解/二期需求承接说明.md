# 二期需求承接说明

这个文件用于后续记录二期需求的拆解过程。每个需求建议单独开一节，先写清影响面，再开始改代码。

## 使用方式

每次二期需求开始前，先补充以下信息：

- 需求名称
- 需求来源
- 目标用户：后台管理员 / App 用户 / 外部系统 / 定时任务
- 涉及端：后台 / App / 前端 / 回调 / 定时 / SQL
- 涉及表
- 涉及接口
- 涉及金额、奖励、等级、订单状态的风险点
- 验证方式
