# 后续开发阅读索引

二期需求开始时，优先读本文件，再按需求类型进入对应文档和源码入口。

## 通用阅读顺序

1. 先读 `doc/00-项目说明/项目总览.md`
2. 再读 `doc/01-基础能力/技术栈与启动配置.md`
3. 根据需求类型读下面的专题文档
4. 最后打开对应 Controller、Service、Domain、Mapper XML

## 按需求类型定位

### 后台管理页面改动

先读：

- `doc/03-接口与回调/接口入口总览.md`
- `doc/02-业务模块/业务模块总览.md`

重点源码：

- 前端页面：`xms-ui/src/views/xms/<模块名>/index.vue`
- 前端 API：`xms-ui/src/api/xms/<模块名>.js`
- 后台 Controller：`xms/neptune-admin/src/main/java/com/xms/web/controller/xms/*Controller.java`
- 后台业务 service：`xms/neptune-admin/src/main/java/com/xms/web/service/impl`
- 业务数据层：`xms/xms-dao/src/main/java/com/xms/dao`

## 二期需求落地建议

每个二期需求建议先写到：

- `doc/需求拆解/二期需求承接说明.md`

每个需求至少记录：

- 需求目标
- 涉及端：后台 / App / 定时 / 回调 / SQL
- 涉及表
- 涉及接口
- 影响资金、奖励、等级、订单状态的风险点
- 验证方式
