# Neptune 项目总览

本文档用于后续二期需求开始前快速建立项目上下文。内容来自当前代码扫描，重点记录后续开发最容易反复用到的入口。

## 顶层结构

项目根目录：

- `xms/`：Java 后端 Maven 多模块项目。
- `xms-ui/`：Vue2 + Element UI 管理后台。
- `doc/`：项目理解文档与后续需求拆解文档。
- `README.md`：根说明文件。

## 后端模块

后端父工程是 `xms/pom.xml`，模块如下：

- `xms-common`：公共基础能力，包含 Redis、Redisson、JWT、返回结构、异常、工具类、Excel、锁、异步消息基础设施。
- `xms-framework`：RuoYi 后台框架层，包含 Web、安全、数据源、配置等后台基础设施。
- `xms-system`：RuoYi 系统管理模块，用户、角色、菜单、部门、字典、参数、日志等。
- `xms-quartz`：定时任务模块，围绕 `sys_job` / `sys_job_log` 和 Quartz 调度。
- `xms-generator`：RuoYi 代码生成模块。
- `xms-dao`：核心业务数据层，包含业务 domain、mapper、mapper XML、基础业务 service。
- `neptune-admin`：后台管理服务启动模块，对应 `xms-ui`。
- `neptune-app`：用户侧 App/API 服务启动模块，包含 App 接口、外部回调、WebSocket 等。

## 启动入口

- 管理后台服务：`xms/neptune-admin/src/main/java/com/xms/web/XmsApplication.java`
  - `@SpringBootApplication(exclude = DataSourceAutoConfiguration.class, scanBasePackages = {"${xms.auto-scan-package}"})`
  - `@MapperScan("com.xms.**.mapper")`
  - 开启 `@EnableAsync`、`@EnableRetry`

- App/API 服务：`xms/neptune-app/src/main/java/com/xms/app/AppApplication.java`
  - `@SpringBootApplication(exclude = {DataSourceAutoConfiguration.class, SecurityAutoConfiguration.class}, scanBasePackages = {"com.xms"})`
  - 开启 `@EnableWebSocket`、`@EnableAsync`、`@EnableRetry`、`@EnableWebSecurity`

## 前端结构

前端目录是 `xms-ui/`，来自 RuoYi-Vue 风格：

- `src/api/xms/`：XMS 后台业务 API 封装。
- `src/views/xms/`：XMS 后台业务页面。
- `src/api/system/`、`src/views/system/`：RuoYi 系统管理。
- `src/api/monitor/`、`src/views/monitor/`：监控、任务、日志。
- `vue.config.js`：Vue CLI 配置，开发代理使用 `VUE_APP_BASE_API` 和 `VUE_APP_TARGET`。

## 技术栈

后端：

- Java 21
- Spring Boot 3.3.4
- Maven 多模块
- MyBatis Plus 3.5.7
- PageHelper
- Druid 动态数据源
- Redis / Redisson
- Redis Stream 自定义监听
- Quartz 定时任务
- Undertow
- Log4j2
- Swagger / Springfox
- Hutool、Fastjson/Fastjson2
- Canal、RocketMQ 依赖存在，当前配置里 RocketMQ 多处为关闭或注释状态
- Web3j、bitcoinj、Binance wallet、Udun SDK 等链上/钱包相关依赖

前端：

- Vue 2.6.12
- Vue CLI 4
- Element UI 2.15.12
- Vue Router、Vuex
- Axios
- ECharts
