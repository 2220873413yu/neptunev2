# 核心表结构索引

表名主要来自 `@TableName`、Mapper XML 和 SQL 文件。字段含义以 Domain、Mapper XML、数据库 DDL 为准。

## 表结构入口

- Domain：`xms/xms-dao/src/main/java/com/xms/dao/domain`
- Mapper 接口：`xms/xms-dao/src/main/java/com/xms/dao/mapper`
- Mapper XML：`xms/xms-dao/src/main/resources/mapper`
- DDL：`xms/a-doc/script-DDL/V1.1/DDL.sql`
- 独立 SQL：`xms/xms-dao/src/main/resources/sql/t_withdraw_fee_share_stat_day.sql`

## 用户与关系

- `t_user_info`：用户基础信息，Domain 不在本次 `@TableName` 扫描结果中，但 Mapper 和 Controller 存在。
- `t_user_relation`：用户关系/上下级关系。
- `t_user_info_snapshot`：用户信息快照。
- `t_user_level_config`：用户等级配置。
- `t_user_level_change_log`：用户等级变更日志。
- `t_user_invest_layer_config`：用户投资层级配置。
- `t_user_income_summary`：用户收益汇总。

建议源码：

- `UserInfoMapper.xml`
- `UserRelationMapper.xml`
- `UserIncomeSummaryMapper.xml`
- `UserLevelConfigMapper.xml`
